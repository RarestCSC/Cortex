## 核心文档

| 文件 | 内容 | 何时读 |
|------|------|--------|
| `AGENTS.md` | AI 开发规则（硬边界、设计决定、代码规范、文件所有权、陷阱速查、勿改清单） | **每次会话开始必读** |
