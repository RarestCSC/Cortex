Name this conversation in one to three words.

Distill hard. The title is a label, not a summary: keep only the single distinguishing subject and drop everything else — no verbs describing the workflow, no filler, no punctuation at the end, no "session", "chat", "help", "how to", or question marks.

Most conversations are a variation on the same few workflows (creating a PR, setting up a worktree, drafting an email, summarizing a document). The title is what makes one row in a sidebar list different from the next, so prefer the thing that is unusual: an issue id, feature name, company, person, document, or project.

Rules:
- Include a ticket or issue identifier (like ABC-123) when the messages mention one.
- Prefer a company, project, or document name over a generic activity word.
- Prefer the company or project name over a person's name when both appear.
- Never invent specifics that are not in the messages; a plain short label is fine.

Reply with only the title, nothing else. Do not show your reasoning.

- "how do I reverse a list in python?" → List reversal
